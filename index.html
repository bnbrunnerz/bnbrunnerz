How minting will work

  1. Get a Binance Agent ID

    Minting is gated by Agent ID for everyone, owner included. No Agent ID, no public mint. Trading and transfers are not gated.

  2. Open this page in your wallet browser

    Use OKX Wallet on BNB Chain. The page checks the chain and switches to BNB (56) when you connect.

  3. Mint your free runner first

    The art is generated by the contract from your token ID. It shows in your wallet and on marketplaces straight from the chain.

Questions

When does mint open?+

Right after the contract is deployed and the treasury is minted. There is no fixed date yet. The open announcement goes out on X first, and this page updates with the contract address and mint button at the same time.

What do I need to mint?+

A Binance Agent ID, a wallet such as OKX on BNB Chain (56), and a small amount of BNB for gas. Your first mint is free apart from gas. Later mints are $0.10 each, charged in BNB at the Chainlink BNB/USD rate.

Is every runner really unique?+

Yes. The contract maps each token ID to its own spot in the full set of possible images, using a step that never lands on the same spot twice. All 10,000 runners come out different.

Is the art really on-chain?+

Yes. Each token's 32×32 SVG artwork and its metadata are generated by the contract from the token ID. There are no image files hosted on IPFS or a website server for the tokens themselves.

Can I trade runners without an Agent ID?+

Yes. The Agent ID gate applies to minting only. Transfers are open to everyone, and normal marketplace trading does not need an Agent ID.

Where does the mint money go?+

Paid mint proceeds are forwarded in the same mint transaction to the payout wallet set once in the contract at deploy. The contract itself keeps a 0 balance and has no withdraw function for mint proceeds.

Is this the original Chain Runners collection?+

No. BNB Runnerz is its own collection on BNB Chain, with its own name, contract and art, built in a similar CC0 pixel runner spirit. It is not affiliated with the original collection.
