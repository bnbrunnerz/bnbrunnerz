BNB Runnerz

10,000 pixel runners on BNB. Agent ID required. First mint free.

BNB Runnerz (BNBR) is a fully on-chain 32x32 pixel runner collection on BNB Smart Chain. Every runner is generated on-chain from a unique permutation of its tokenId, no IPFS images.

Mint

Mint is NOT live yet. Contract is built and ready for deploy, but not deployed on-chain yet. Do not trust any other contract address for BNB Runnerz.

  • Supply: 10,000, max 10 per wallet
  • Price: 1st mint per wallet FREE, next mints $0.10 each via Chainlink BNB/USD
  • Agent ID gate: mint only, Binance Agent ID required for everyone including owner
  • Royalty: 1% fixed (ERC-2981)
  • Treasury: 100 tokens to the payout wallet, minted by owner first before public mint
  • Payout: 0x5b92f2d1231148a711619a3880fd794fc6ac4e04, immutable, paid mint proceeds forwarded in the same transaction, contract balance stays 0

When mint opens, minting will be through the deploy/mint page, with OKX wallet on BNB chain 56. No private key is ever asked for on this site.

FAQ

What do I need to mint?
A Binance Agent ID, an OKX wallet on BNB chain 56, and BNB for gas. First mint per wallet is free, rest are $0.10 each.

Can I trade BNB Runnerz?
Yes, transfers are open to everyone. Only minting is gated by Agent ID.

Where does mint money go?
Paid mint proceeds go in the same mint transaction to the payout wallet. The contract keeps 0 balance and has no withdraw function for mint proceeds.

Is the art on-chain?
Yes, fully on-chain SVG, 32x32 pixel runner, generated from a unique permutation of the tokenId.

BNB Runnerz is a new collection inspired by the CC0 pixel runner style, with its own name, art and contract. It is not the original Chain Runners collection.
